# 🌐 Personal Portfolio Website

A professional and responsive personal portfolio website built during my web development internship.

## 👨‍💻 About

This portfolio showcases my skills, education, experience, and projects as a Web Developer.

The website is built using HTML, CSS, JavaScript, Node.js, Express.js and EJS.

## 🚀 Features

- Responsive portfolio design
- About section
- Education section
- Skills section
- Experience section
- Projects section
- Contact section
- Dynamic portfolio data using EJS
- Backend using Node.js and Express.js
- Deployed using Render

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- EJS
- Git & GitHub
- Render
